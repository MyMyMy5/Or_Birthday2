# Implementation Tasks

## Task 1: Add Thumbnail Store utility functions
- [x] 1.1 In `script.js`, add a `THUMBNAIL_STORAGE_KEY` constant set to `'song_thumbnails'` and three utility functions: `getCustomThumbnail(songId)` that reads the `song_thumbnails` object from localStorage and returns the value for the given songId (or null), `setCustomThumbnail(songId, imageSource)` that reads the object, sets the key, and writes back, and `removeCustomThumbnail(songId)` that reads the object, deletes the key, and writes back. All functions should handle localStorage errors gracefully. #[[.kiro/specs/song-thumbnail/requirements.md]] Requirements 4.1, 4.3

## Task 3: Build the Thumbnail Editor modal
- [x] 3.1 In `script.js`, create an `openThumbnailEditor(songId, defaultCover)` function that creates and displays a modal overlay (`.thumbnail-editor-modal`) containing: a preview image showing the current cover, an "Upload Image" button with a hidden file input (accept="image/jpeg,image/png,image/gif,image/webp,image/avif"), a URL text input with a "Set URL" button, a "Reset to Default" button, an error message paragraph, and a "Cancel" button. The modal should close when Cancel is clicked or when clicking the backdrop. #[[.kiro/specs/song-thumbnail/requirements.md]] Requirements 1.2, 2.1, 3.1, 6.1
- [x] 3.2 In the `openThumbnailEditor` function, implement the file upload handler: when a file is selected, validate its MIME type against `['image/jpeg', 'image/png', 'image/gif', 'image/webp', 'image/avif']`. If invalid, show error "Unsupported file type. Please use JPEG, PNG, GIF, WebP, or AVIF." If valid, use FileReader to read as data URL, call `setCustomThumbnail(songId, dataUrl)`, update the song card's `<img>` src immediately, update the modal preview, and clear any error. #[[.kiro/specs/song-thumbnail/requirements.md]] Requirements 2.1, 2.2, 2.3, 5.3
- [x] 3.3 In the `openThumbnailEditor` function, implement the URL submit handler: when the user clicks "Set URL", validate the input using `MediaManager._isValidUrl(url)`. If invalid, show error "Invalid URL. Please enter a valid http:// or https:// URL." If valid, call `setCustomThumbnail(songId, url)`, update the song card's `<img>` src immediately, update the modal preview, and clear any error. #[[.kiro/specs/song-thumbnail/requirements.md]] Requirements 3.2, 3.3, 5.3
- [x] 3.4 In the `openThumbnailEditor` function, implement the reset handler: when "Reset to Default" is clicked, call `removeCustomThumbnail(songId)`, set the song card's `<img>` src back to `defaultCover`, update the modal preview to show the default, and clear any error. #[[.kiro/specs/song-thumbnail/requirements.md]] Requirements 6.2, 6.3
